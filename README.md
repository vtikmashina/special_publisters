# Pablisters Demo

Статический промо-сайт спецпроектов Паблистеров.

## Структура

- `index.html` — основная страница
- `styles.css` — стили
- `script.js` — интерактив и анимации
- `assets/` — шрифты и изображения
- `texts-for-copywriter.md` — все тексты страницы для редактуры

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Открыть:

```text
http://127.0.0.1:8000/
```

Или через Docker:

```bash
docker compose up --build
```

Открыть:

```text
http://127.0.0.1:8088/
```

## Деплой

Сайт статический и в продакшне запускается через Docker Compose.
Публичный системный nginx оставлен для HTTPS и проксирует сайт на контейнер
`special-publisters-site`, который слушает `127.0.0.1:8088`.
